# 00 — Visión y principios

## Qué es

El Innovatón es una experiencia presencial breve de Espacio IDI + Educai en la que una persona:

```
descubre una hipótesis sobre cómo puede aportar
→ la pone en juego sobre un problema real
→ genera evidencia de lo que hizo
→ reflexiona sobre su aporte
→ recibe una interpretación inicial
→ conecta con una próxima experiencia
```

No busca decirle a la persona “quién es”, resolverle su carrera profesional ni producir un diagnóstico psicométrico.

El objetivo es pasar de:

> “No sé bien qué puedo aportar.”

a:

> “En esta situación concreta hice esto, aporté de esta manera y ahora tengo una señal más sobre mis capacidades.”

## Tesis de Educai aplicada

Educai parte de una tesis central:

> El aprendizaje se entiende mejor observando la evidencia que una persona genera mientras aprende, no solamente sus resultados finales.

Aplicado al Innovatón:

- el cuestionario inicial genera una **hipótesis**;
- el sprint produce una **experiencia**;
- las acciones, el A3, el pitch, la evaluación del founder y la reflexión producen **evidencia**;
- Educai interpreta esa evidencia como **señales de capacidades**;
- luego propone un **próximo experimento**.

## Loop central

```
Experiencia
→ Evidencia
→ Interpretación
→ Recomendación
→ Nueva experiencia
→ Nueva evidencia
```

## Modos visibles de la experiencia

### Explorar
Entender, preguntar, detectar supuestos, encontrar información faltante.

### Crear
Abrir posibilidades, conectar ideas, cambiar de perspectiva.

### Impulsar
Priorizar, decidir, concretar y diseñar una primera prueba.

Estos tres modos son una capa pedagógica simple del Innovatón.

**No son la arquitectura permanente de capacidades de Educai.**

## Capacidades internas

Educai registra señales más granulares:

- comprensión del problema;
- cuestionamiento de supuestos;
- generación de alternativas;
- síntesis y priorización;
- experimentación / validación;
- comunicación y colaboración.

## Principios

1. Experiencia presencial > interacción con el celular.
2. Robustez > sofisticación.
3. Claridad > originalidad.
4. Operabilidad > automatización.
5. Evidencia observable > autopercepción aislada.
6. Ausencia de evidencia ≠ ausencia de capacidad.
7. Una experiencia genera señales, no conclusiones definitivas.
8. Matching simple > matching inteligente.
9. Todo debe tener contingencia manual.
10. El sistema debe poder seguir funcionando si internet falla.

## Qué valida esta primera versión

Puede explorar:

- si una hipótesis breve de aporte le resulta razonable a la persona;
- si esa hipótesis le ayuda a entrar en acción;
- si después del sprint reconoce mejor cómo contribuyó;
- si la experiencia aumenta claridad percibida;
- si Educai puede convertir una experiencia real en evidencia contextualizada y una próxima acción.

No valida:

- precisión psicométrica;
- capacidades profesionales estables;
- predicción de desempeño;
- orientación vocacional;
- causalidad del matching;
- aprendizaje de largo plazo.
