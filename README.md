## Regla de producto

La tecnología organiza la experiencia, pero no debe convertirse en protagonista ni ser condición para que el evento continúe.

El loop central es:

```
Experiencia
→ Evidencia
→ Interpretación
→ Recomendación
→ Nueva experiencia
```

El cuestionario inicial genera una **hipótesis**. La experiencia genera la **evidencia**.
